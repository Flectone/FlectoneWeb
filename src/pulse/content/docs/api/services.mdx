Любой компонент берётся через инжектор, создавать реализации руками нельзя

```java
FlectonePulse flectonePulse = FlectonePulseAPI.getInstance();

FPlayerService fPlayerService = flectonePulse.get(FPlayerService.class);
```

Все компоненты живут в одном экземпляре, поэтому повторный `get()` отдаст тот же самый объект

<br></br>

| `ModerationService` | Баны, муты, варны, кики, вайтлист и нарушения |
| `ExternalModerationService` | Наказания, о которых сообщают другие плагины наказаний |
| `PlaytimeService` | Наигранное время и AFK сессии |
| `SkinService` | Скины, аватары и изображения тела |
| `TranslationService` | Загрузка переводов платформы |
| `MetricsService` | Сбор и отправка статистики |

### ModerationService

Одна точка для всей работы с наказаниями

```java
import net.flectone.pulse.model.value.Moderation;
import net.flectone.pulse.service.ModerationService;

ModerationService moderationService = flectonePulse.get(ModerationService.class);

// выдать мут на час
moderationService.mute(fPlayer, System.currentTimeMillis() + 3_600_000L, "Спам", moderatorId);

// проверить активный бан
boolean banned = moderationService.hasValid(fPlayer, Moderation.Type.BAN);

// получить активное наказание
Optional<Moderation> mute = moderationService.getValid(fPlayer, Moderation.Type.MUTE);
```

| Группа методов | Примеры |
|----------------|---------|
| Выдача | `ban`, `mute`, `warn`, `kick`, `maintenance`, `whitelist`, `add` |
| Проверка | `hasValid`, `getValid`, `getValidNames`, `getTotalValidCount` |
| Снятие | `remove` |
| Нарушения | `addViolation`, `isViolationRestricted`, `getFirstViolationTimestamp` |
| Ограничения | `isAllowedTime`, `hasHigherGroupThan` |
| Кэш | `invalidate` |

Типы наказаний в `Moderation.Type` это `BAN`, `MUTE`, `WARN`, `KICK`, `WHITELIST`, `MAINTENANCE` и парные им снятия `UNBAN`, `UNMUTE`, `UNWARN`, `UNWHITELIST`, `UNMAINTENANCE`

# Планировщик

<span>Пакет `net.flectone.pulse.scheduler`</span>

`TaskScheduler` работает одинаково на всех платформах, включая Folia. Время задаётся в тиках

```java
import net.flectone.pulse.scheduler.TaskScheduler;

TaskScheduler taskScheduler = flectonePulse.get(TaskScheduler.class);

// асинхронно прямо сейчас
taskScheduler.runAsync(() -> loadDataFromDatabase());

// асинхронно через 5 секунд
taskScheduler.runAsyncLater(() -> sendDelayedMessage(), 100L);

// каждые 30 секунд
taskScheduler.runAsyncTimer(() -> updateStatistics(), 600L);
```

| Метод | Что делает |
|-------|------------|
| `runAsync(SchedulerRunnable)` | Выполняет задачу асинхронно |
| `runAsync(SchedulerRunnable, boolean independent)` | То же самое, но со значением `false` выполнит сразу, если поток уже асинхронный |
| `runAsyncLater(SchedulerRunnable, long delay)` | Выполняет асинхронно с задержкой, по умолчанию 20 тиков |
| `runAsyncTimer(SchedulerRunnable, long period)` | Выполняет асинхронно по расписанию |
| `runSync(SchedulerRunnable)` | Выполняет задачу синхронно |
| `runSyncLater(SchedulerRunnable, long delay)` | Выполняет синхронно с задержкой |
| `getExecutorService()` | Отдаёт пул потоков планировщика |

Все методы отдают `CompletableFuture<Void>`. У повторяющихся задач он никогда не завершается сам, поэтому отменяй его, когда задача больше не нужна

<Callout type="error" title="Внимание">

Не блокируй основной поток. Любые обращения к базе и сетевые запросы делай через `runAsync`, потому что обработчики событий вызываются синхронно относительно конвейера сообщений

</Callout>

# Конфигурация

<span>Пакет `net.flectone.pulse.file`</span>

`FileFacade` даёт доступ ко всем файлам настроек

```java
import net.flectone.pulse.file.FileFacade;

FileFacade fileFacade = flectonePulse.get(FileFacade.class);

// config.yml
var config = fileFacade.config();
// message.yml
var message = fileFacade.message();
// command.yml
var command = fileFacade.command();
// integration.yml
var integration = fileFacade.integration();
// permission.yml
var permission = fileFacade.permission();
// localizations/ru_ru.yml
var localization = fileFacade.localization("ru_ru");
```

| Метод | Что отдаёт |
|-------|------------|
| `config()`, `message()`, `command()`, `integration()`, `permission()` | Секции своих файлов |
| `localization()` | Локализацию по умолчанию |
| `localization(String locale)` | Локализацию конкретного языка |
| `localizations()` | Все загруженные локализации |
| `saveFiles()`, `updateFiles()` | Сохраняют и обновляют файлы |

<Callout type="warn" title="Предупреждение">

Считай конфигурацию доступной только для чтения. Менять настройки FlectonePulse из своего плагина не рекомендуется

</Callout>

# Логирование

<span>Пакет `net.flectone.pulse.logging`</span>

`FLogger` умеет писать цветной текст в консоль

```java
import net.flectone.pulse.logging.FLogger;

FLogger fLogger = flectonePulse.get(FLogger.class);

fLogger.info("Сообщение");
fLogger.warning("Предупреждение");

if (FLogger.DEBUG_ENABLED) {
    // debug режим включён через -Dflectonepulse.debug=true
}
```
