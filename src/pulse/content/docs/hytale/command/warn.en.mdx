### `null_player`

Message if the entered player is not found

### `null_time`

Message if an impossible time duration is entered

### `lower_weight_group`

Message if the command is executed by a player with a group lower than the player being moderated

### `reasons`

A list of keys and values where the key is a word and the value is a specific reason

<Callout type="info" title="Information">
    You can add your own reasons, for example

    ```yaml
    random_kek: "Random reason"
    ```
    Then if I type `/warn player 1d random_kek`, the reason will be `Random reason`

    If no reason is specified, `default` will be used
</Callout>

### `server`

Message broadcasted to everyone

### `person`

Message for the player receiving the warning

### `check_group_weight`

Whether player groups will be checked. If the player being moderated has a higher role than the command sender, the command will not execute and a `lower_weight_group` error will occur

<include>../../../../parts/range.en.mdx</include>

### `time_limits`

Time limits based on the sender's group weight. The key is the group weight, and the value is the maximum moderation time in milliseconds (`1` second = `1000` milliseconds)

<Callout type="info" title="Information">
    Example

    ```yaml
    time_limits:
      20: 35000
      50: 100000
    ```

    - If a player has a group weight of `10`, the command will NOT be executed
    - If a player has a group weight of `20`, the maximum time will be `35000`
    - If a player has a group weight of `40`, the maximum time will also be `35000`
    - If a player has a group weight of `50` or higher, it will be `100000`

    For unlimited time, use the value `-1`

    If the list is empty, nobody has any time limits

</Callout>

### `reason_times`

Punishment time for the reasons from `reasons` in the localization. The key is the reason and the value is its time (`1d2h3m4s`)

<Callout type="info" title="Information">
    Example

    ```yaml
     reason_times:
       default: "1h"
       1.1.1: "60m"
       1.2.1: "7d"
    ```

    - The reason `1.1.1` gives `60` minutes, and `1.2.1` gives `7` days
    - A reason that is not listed here gives `1` hour from `default`
    - The time entered in the command is always more important than the time from here

    For unlimited time, use the value `-1`

</Callout>

<include>../../../../parts/aliases.en.mdx</include>

### `actions`

A list where the key is the `number` of warnings and the value is the `action` to be executed

<Callout type="info" title="Information">
    For example, if I want a player to be banned at 10 warnings then I should enter `10: ban <target> ohh`. The action will trigger if the player reaches `10` active warnings.
</Callout>
