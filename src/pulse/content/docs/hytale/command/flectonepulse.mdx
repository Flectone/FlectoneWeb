![command flectonepulse](/pulse/hytale/command_flectonepulse.webp)

Комманда используется как `/flectonepulse тип [файл]`, где тип это одно из действий ниже

| Тип          | Объяснение                                                                                                                                              |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| `reload`     | Перезагружает `FlectonePulse` вместе со всеми конфигами                                                                                                 |
| `dump`       | Загружает информацию о сервере и плагине на `pastes.dev` и возвращает ссылку. Это удобно скидывать в поддержку, если что-то не работает                  |
| `editor`     | Запускает веб-редактор конфигов и возвращает ссылку на него. Нужно, чтобы `host` и `port` были настроены в `command.yml`                                 |
| `export`     | Сохраняет папку `FlectonePulse` в `.zip` архив рядом с конфигами, без папок `libraries`, `backups`, `minecraft` и файлов базы данных `.db`               |
| `export_all` | Тоже самое, что и `export`, но со всеми файлами                                                                                                         |
| `import`     | Распаковывает `.zip` архив обратно в папку `FlectonePulse` и перезагружает плагин. Архив должен лежать в папке `FlectonePulse`                           |
| `database_export` | Сохраняет базу данных в `.json` файл рядом с конфигами                                                                                              |
| `database_import` | Загружает базу данных из `.json` файла и перезагружает плагин. Файл должен лежать в папке `FlectonePulse`                                            |

<Callout type="info" title="Информация">
    Вторым аргументом можно указать название файла для `export`, `export_all`, `import`, `database_export` и `database_import`, например `/flectonepulse export myconfig`. Если его не написать, то будет использовано название `export_дата_время` или `database_дата_время` для базы данных
</Callout>

### `dump_error`

Сообщение при возникновении ошибки загрузки дампа

### `database_error`

Сообщение при возникновении ошибки во время экспорта или импорта базы данных

### `null_host_editor`

Сообщение, когда поле `host` в config.yml пустое

### `null_port_editor`

Сообщение, когда `port`, который указан в config.yml, занят или недоступен

### `null_file`

Сообщение, когда не существует файл, который указан в `/flectonepulse import файл`

### `file_exist`

Сообщение, когда файл уже существует, который указан в `/flectonepulse export файл`

### `format_starting`

Сообщение при старте выполнения команды

### `format_false`

Сообщение при возникновении ошибки

### `format_true`

Формат сообщения, которое будет отправлено при перезагрузке всего `FlectonePulse`

### `format_dump`

Формат сообщения, которое будет отправлено при успешной загрузке дампа

### `format_editor`

Формат сообщения, которое будет отправлено при успешном запуске веб-сервера

### `format_export`

Формат сообщения, которое будет отправлено при успешном экспорте

### `format_import`

Формат сообщения, которое будет отправлено при успешном импорте

### `format_database_export`

Формат сообщения, которое будет отправлено при успешном экспорте базы данных

### `format_database_import`

Формат сообщения, которое будет отправлено при успешном импорте базы данных

### `editor`

Веб-редактирование для FlectonePulse. Backend сервер запускается тамже, где установлен FlectonePulse

![editor](/pulse/command_flectonepulse_editor.webp)

<Accordions>
    <Accordion title="Настройка редактора">
        #### `host`

        Хост (айпи) текущего сервера, можно указывать и домен

        #### `https`

        Включает работу `https`, вместо `http`

        #### `port`

        Незанятый порт текущего сервера
    </Accordion>
</Accordions>

### `execute_in_main_thread`

Будет ли выполняться вся перезагрузка в главном потоке сервера
