### `format_true`

Сообщение при включении слежки

### `format_false`

Сообщение при выключении слежки

### `format_log`

Формат сообщения, которое будет отправлено при слежке за действием

### `actions`

Список действий с их локализацией для `format_log`. Если локализации у действия нет, то название действией и будет его локализацией

### `categories`

Список категорий с действиями, за которыми происходит слежка

| Категория | Объяснение                                                                                                                                    |
|-----------|------------------------------------------------------------------------------------------------------------------------------------------------|
| `command` | Список названий комманд, за которыми происходит слежка, например `tell` или `anon`                                                            |
| `action`  | Список остальных действий, за которыми происходит слежка: `anvil`, `book`, `sign` и названия чатов, например `local` (для прокси это `chat`)  |

<Callout type="info" title="Информация">
    Название действия можно перевести в локализации в `actions`, иначе оно будет показано так, как написано здесь
</Callout>
