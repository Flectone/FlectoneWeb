<Callout type="warn" title="Предупреждение">
По умолчанию администраторов сервера нельзя упоминать из-за права `bypass`

Если упомянутый игрок в ванише и отправитель его не видит, то упоминание в сообщении останется, но пинга не будет
</Callout>

Это форматирование позволяет упоминать (пинговать) человека в сообщении. Также можно упоминать и донатные группы, например `@default`
![mention](/pulse/hytale/message_format_mention.webp)

### `trigger`

Символ, с которого должно начинаться сообщение упоминания

<Callout type="info" title="Информация">
Если я хочу упомянуть `Terrona`, то я должен написать `@Terrona`
![mention](/pulse/hytale/message_format_mention.webp)
</Callout>

### `name_pattern`

Регулярное выражение, по которому упоминание ищется в сообщении. `<trigger>` внутри заменится на символ из `trigger`

<Callout type="info" title="Информация">
По умолчанию упоминанием считаются буквы, цифры, `_` и `.`, при этом последним символом не может быть точка, чтобы `@Flectone.` в конце предложения тоже работало

Если хочешь, чтобы упоминались только латинские ники, напиши `<trigger>([A-Za-z0-9_]+)`
</Callout>

### `everyone_tag`

Слово, которое в сочетании с `trigger` будет упоминать всех игроков на сервере. Чтобы это использовать, необходимо иметь право `flectonepulse.module.message.format.mention.group.default`

### `group`

Право для упоминания донатной группы, например `@default`

<Callout type="idea" title="Примечание">
Для каждой группы проверяется своё право `flectonepulse.module.message.format.mention.group.название_группы`

</Callout>

### `bypass`

Право для игнорирования упоминания
