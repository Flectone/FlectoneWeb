# Что такое FlectonePulse и для чего он нужен?
FlectonePulse – это плагин для серверов Minecraft, который позволяет полностью настраивать сообщения, чат, команды и интеграции. Он предоставляет гибкую систему форматирования текста, автоматическое определение языка игроков и интеграции с Discord, Telegram и Twitch

| Платформа                                    | Версии                      |
|----------------------------------------------|-----------------------------|
| Bukkit / Spigot / Paper / Purpur / Folia     | 1.8.8 и до самой последней  |
| Fabric                                       | Последняя версия Minecraft  |
| NeoForge                                     | Последняя версия Minecraft  |
| BungeeCord / Waterfall                       | Последняя версия            |
| Velocity                                     | Последняя версия            |

<Callout type="warn" title="Предупреждение">
    Нужна Java 17 или выше. Старые версии Minecraft, например 1.8.8, тоже можно запустить на Java 17 (посмотри [PandaSpigot](https://github.com/hpfxd/pandaspigot))
</Callout>

<Callout type="info" title="Информация">
    Есть и версия для [Hytale](/pulse/docs/hytale/), у неё своя документация, потому что часть модулей там работает по-другому
</Callout>

| `integration.yml`   | [Интеграции](/pulse/docs/integration/)                                               | Настройка взаимодействий с внешними плагинами и сервисами.                                                                                                                   |
| `message.yml`       | [Сообщения](/pulse/docs/message/)                                                    | Настройка сообщений FlectonePulse (условия их появления и содержание).<br/> **Не путать с настройкой формата сообщений**, которая выполняется в файлах `/localizations/...`. |
| `localizations/...` | Указано в каждом пункте документации команд и сообщений                        | В этой папке находятся файлы с настройками для каждого языка игроков ([см. язык](/pulse/docs/config/language/)). Здесь настраивается **формат** сообщений, т.е. текст.             |
| `permission.yml`    | Указано в каждом пункте документации команд, сообщений и интеграций            | Настройка прав доступа. По умолчанию права настроены так, чтобы большинство функций были доступны всем игрокам без необходимости дополнительной настройки.                   |

# Как настроить форматирование сообщений?
FlectonePulse обладает универсальной системой форматирования текста, поддерживающей различные цветовые форматы – от классических кодов до современных градиентов.

```yaml

```

# Можно ли отключить определённые функции плагина?
Да, FlectonePulse использует модульную систему. Любую функцию (команды, сообщения или интеграции) можно отключить в файлах `command.yml`, `message.yml` или `integration.yml` соответственно. После внесения изменений перезапустите плагин командой `/flectonepulse reload`.

<Callout type="info" title="Информация">
    Каждый модуль зависит от родителя, который находится выше. Если выключить `message.enable`, то выключатся и все сообщения внутри, даже если у них `enable: true`. Подробнее в [конфигурации](/pulse/docs/config/internal/)
</Callout>

<br></br>

# Как работает автоматическое определение языка?
Если в `config.yml` включена опция `by_player`, плагин автоматически определяет язык Minecraft игрока и отображает сообщения из папки `localizations/...` на этом языке. Если локализация недоступна, используется язык по умолчанию из конфигурации. Подробности в [документации по локализации](/pulse/docs/config/language/).

<br></br>

# Какие интеграции поддерживает FlectonePulse?
Плагин интегрируется с Discord, Telegram и Twitch, позволяя игрокам общаться через разные платформы. Также поддерживаются сторонние плагины Minecraft, например `LuckPerms` и `Vault` для прав и групп, `PlaceholderAPI` и `MiniPlaceholders` для плейсхолдеров, `SkinsRestorer` для скинов, `PlasmoVoice` и `SimpleVoice` для запрета говорить игрокам с мутом, `LiteBans`, `LibertyBans`, `AdvancedBan` и `CMI` для модерации. Настройка интеграций выполняется в файле `integration.yml`. Подробности в [документации по интеграциям](/pulse/docs/integration/).

<br></br>

# Почему команды или сообщения не работают у обычных игроков?
Скорее всего дело в правах. Все права находятся в `permission.yml`, у каждого есть `name` (название права) и `type` (кому оно доступно по умолчанию).

<Callout type="warn" title="Предупреждение">
    Если в `LuckPerms` стоит правило `* false` (т.е. все права отключены и выдаются вручную), то права с `type: "TRUE"` тоже перестанут работать. Для этого есть настройка [`always_have_true`](/pulse/docs/integration/luckperms/) в `integration.yml`
</Callout>

Чтобы выдать право конкретной группе, возьми `name` нужного права из `permission.yml` и выдай его, например `/lp group default permission set flectonepulse.module.command.me true`

<br></br>

# Сообщение не появляется, что проверить?
<Steps>
    <Step>
        Включен ли сам модуль и его родитель в `message.yml` или `command.yml` (`enable: true`)
    </Step>
    <Step>
        Есть ли у игрока право этого модуля из `permission.yml`
    </Step>
    <Step>
        Подходит ли `range`, например с `range: 100` сообщение увидят только те, кто рядом
    </Step>
    <Step>
        Не пустая ли строчка в файле локализации, потому что пустое сообщение не отправляется
    </Step>
    <Step>
        Перезагрузи плагин с помощью `/flectonepulse reload` и посмотри в консоль
    </Step>
</Steps>

<br></br>

# Как отправлять сообщения из Minecraft в Discord или Telegram?
Впиши токен бота в `integration.yml`, включи интеграцию и добавь нужный тип сообщения в `message_channel`, где значением является ID канала

```yaml
message_channel:
  MESSAGE_CHAT_GLOBAL:
    - "123456"
  COMMAND_BAN:
    - "123456"
```

Названия типов сообщений совпадают с названиями модулей, например `COMMAND_BAN` или `MESSAGE_CHAT_GLOBAL`. Для своего чата с названием `admin` это будет `MESSAGE_CHAT_ADMIN`

<Callout type="info" title="Информация">
    ID канала в Telegram можно узнать командой `!id` прямо в чате, если бот туда добавлен. Подробности в документации [Discord](/pulse/docs/integration/discord/), [Telegram](/pulse/docs/integration/telegram/) и [Twitch](/pulse/docs/integration/twitch/)
</Callout>

<br></br>

# Почему в чате не отображаются головы, иконки и текстуры?
Модуль [object](/pulse/docs/message/format/object/) работает только для игроков, которые играют на версии `1.21.9` и выше. Все остальные вместо головы или иконки увидят обычный символ из `default_symbol`

<br></br>

# Почему сообщения в чате дублируются?
Чаще всего это другой плагин, который тоже отправляет сообщение. Проверь `cancel` у чата в `message.yml` – с `cancel: false` FlectonePulse не отменяет ивент, поэтому сообщение может отправить и сервер, и другой плагин.

Также дублирование бывает с плагинами, которые изменяют пакеты чата (например `InteractiveChat`) или с `DiscordSRV`, если у него включены свои Webhook сообщения. Подробности в [чате](/pulse/docs/message/chat/#mode)

<br></br>

# Как перенести все настройки на другой сервер?
Для этого есть готовые команды
<Steps>
    <Step>
        На первом сервере напиши `/flectonepulse export`, это создаст `.zip` архив в папке `FlectonePulse`
    </Step>
    <Step>
        Перенеси этот архив в папку `FlectonePulse` на другом сервере
    </Step>
    <Step>
        Напиши `/flectonepulse import название_архива`, после чего плагин перезагрузится уже с новыми настройками
    </Step>
</Steps>

Подробности в [документации команды](/pulse/docs/command/flectonepulse/)

# Что происходит с конфигами при обновлении плагина?
FlectonePulse сам добавляет новые настройки и переносит старые значения, поэтому конфиги удалять не нужно. Перед этим создаётся копия старых файлов и базы данных в папке `FlectonePulse/backups/старая_версия`

<Callout type="warn" title="Предупреждение">
    Не изменяй `version` в `config.yml` вручную, по нему плагин понимает, с какой версии нужно переносить настройки
</Callout>

<br></br>

# Поддерживает ли FlectonePulse PlaceholderAPI?
Да, FlectonePulse полностью совместим с PlaceholderAPI и MiniPlaceholders. Используйте плейсхолдеры в сообщениях.

FlectonePulse добавляет и свои плейсхолдеры, например `%flectonepulse_ping%` или `%flectonepulse_online_total_formatted%`. Полный список есть в документации [PlaceholderAPI](/pulse/docs/integration/placeholderapi/) и [MiniPlaceholders](/pulse/docs/integration/miniplaceholders/)

# Чем FlectonePulse отличается от FlectoneChat?
FlectonePulse – это новый проект, а не улучшенная версия FlectoneChat. FlectoneChat был экспериментом, а FlectonePulse создан с учётом прошлых ошибок, предлагая больше возможностей и кастомизации.

# Как настроить ТАБ (список игроков)?
Для включения/отключения модулей ТАБа настройте файл `message.yml`:

```yaml
tab:
  enable: true
  header:
    enable: true
  footer:
    enable: true
  playerlistname:
    enable: true
```

Для изменения сообщений отредактируйте файл локализации `localizations/...`:

```yaml
tab:
  header:
    lists:
    - - " "
      - "<fcolor:1>👾"
      - " "
    - - " "
      - "<fcolor:1>❤"
      - " "
  footer:
    lists:
    - - " "
      - "<fcolor:1>Привет <fcolor:2><nickname><fcolor:1>!"
      - " "
    - - " "
      - "<fcolor:1>ТПС <replacement:tps>, Онлайн <replacement:online>"
      - " "
  playerlistname:
    format: "<!shadow><white><player_head></white></!shadow><world>▋ <reset><prefix><stream><fcolor:2><nickname><afk><mute><suffix>"
```

<Callout type="warn" title="Предупреждение">
Для сортировки ТАБа по донатным группам включите [`tab_sort`](/pulse/docs/integration/luckperms/#tab-sort).
</Callout>

После изменений выполните `/flectonepulse reload`. Подробности в [документации по ТАБ](/pulse/docs/message/tab/).

# Что делать, если возникают ошибки?
<Steps>
    <Step>
        Проверь консоль сервера на наличие ошибок
    </Step>
    <Step>

# Когда выйдет новая версия FlectonePulse с поддержкой последней версии Minecraft?
Скорее всего, FlectonePulse уже поддерживает новейшую версию Minecraft. Экспериментальные версии доступны для скачивания на [GitHub](https://github.com/Flectone/FlectonePulse/actions/) или в [Discord-канале для тестеров](https://discord.com/channels/861147957365964810/1357058707011272926). Если версия Minecraft уже вышла, а обновление FlectonePulse отсутствует, это связано с ожиданием релиза PacketEvents – основной библиотеки, используемой FlectonePulse для взаимодействия с сервером. Как только PacketEvents выйдет в релиз, FlectonePulse будет обновлён.

<Callout type="warn" title="Предупреждение">
Тестовые версии используйте на свой страх и риск. Эти версии чаще всего не созданы для того, чтобы использовать их в продакшене, они могут быть сломаны или сломать вам прошлую версию FlectonePulse
</Callout>

<br></br>

# Работает ли FlectonePulse с прокси и как его настроить?
FlectonePulse поддерживает прокси-серверы, включая BungeeCord и Velocity. Для работы плагина необходимо установить один и тот же файл плагина как на прокси, так и на сервер. На прокси файлы конфигурации не создаются – оно выступает в роли моста. Все настройки выполняются в файлах на серверах. Для корректной работы обязательно нужна серверная база данных (`MySQL`, `MariaDB` или `PostgreSQL`), которая должна быть настроена в файле `config.yml` на серверах. Также нужно включить один из режимов `velocity` или `bungeecord`, подробности в [документации по конфигурации](/pulse/docs/config/proxy/).

<Callout type="info" title="Информация">
    Вместо `BungeeCord` и `Velocity` для связи серверов можно использовать `Redis`, тогда сервера могут быть даже без общего прокси
</Callout>

<br></br>

# Поддерживает ли FlectonePulse ядра, работающие одновременно с модами и плагинами, такие как Arclight или Mohist?

FlectonePulse не тестировался на ядрах, поддерживающих одновременно моды и плагины (например, Arclight или Mohist), и их поддержка не предполагается, но это может работать. Основная проблема заключается в библиотеке PacketEvents, как и на Fabirc/NeoForge, некоторые моды могут создавать собственные протоколы или изменять существующие, что может приводить к вылетам игроков

Отдельные версии для `Fabric` и `NeoForge` работают только на самой последней версии Майнкрафта из-за сложности поддержки мульти-версий

<br></br>

# Твой плагин, использующий чат, и FlectonePulse несовместимы?

По умолчанию `FlectonePulse` имеет настройку `mode: "BUKKIT"` для [чатов](/pulse/docs/message/chat/#mode), с ней сообщения чата видят и другие плагины

<Callout type="info" title="Информация">
    В редких случаях, если твой плагин использует `Paper`-слушатели, нужно поставить `mode: "PAPER"`. А `mode: "PACKET"` наоборот полностью забирает чат себе через `PacketEvents`, с ним другие плагины сообщения не увидят
</Callout>

Если плагин всё равно конфликтует, попробуй изменить `priority` у чата, например на `HIGHEST`, чтобы FlectonePulse изменял сообщение самым последним
