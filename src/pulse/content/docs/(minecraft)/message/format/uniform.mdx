<Callout type="info" title="Информация">
    Модуль перехватывает текст, который сервер отправляет клиенту, и прогоняет его через форматирование FlectonePulse. Это любой текст из Minecraft: чат, action bar, title, boss bar, ТАБ, скорборд, имена сущностей, достижения и названия инвентарей. Включай только те типы, которые действительно нужно форматировать, иначе это может повлиять на другие сообщения и элементы интерфейса
</Callout>

### `types`

<Callout type="warn" title="Важно">
  Включай опции `types` осознанно. FlectonePulse форматирует такой текст как сообщение, отправленное сервером, поэтому к нему применяются теги и форматирование, которые не рассчитаны на игроков. Если в выбранном типе может оказаться текст игрока (например `player_chat` или `entity_name`), лучше не включать эту опцию, иначе игрок сможет влиять на форматирование
</Callout>

Список типов текста, которые FlectonePulse будет дополнительно форматировать. Выключенный тип остаётся в том виде, в котором его отправил сервер или другой плагин

| Тип                | Что форматирует                                    |
|--------------------|----------------------------------------------------|
| `action_bar`       | Сообщения над хотбаром                             |
| `advancement`      | Названия и описания достижений                     |
| `boss_bar`         | Название полосы босса                              |
| `entity_name`      | Имена сущностей                                    |
| `inventory_title`  | Название открытого инвентаря                       |
| `player_chat`      | Сообщения чата                                     |
| `playerlistname`   | Имена игроков в списке                             |
| `scoreboard`       | Названия и значения скорборда                      |
| `system_chat`      | Системные сообщения                                |
| `tab_footer`       | Низ списка игроков                                 |
| `tab_header`       | Верх списка игроков                                |
| `team`             | Название, префикс и суффикс команды                |
| `title`            | Заголовок и подзаголовок                           |

<Callout type="idea" title="Примечание">
    Сообщения, которые уже отформатировал FlectonePulse, повторно не обрабатываются, поэтому свои сообщения не будут затронуты
</Callout>
