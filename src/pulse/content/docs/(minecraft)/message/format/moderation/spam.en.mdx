### `same_message`

Whether only identical messages are considered spam. If `false`, any message sent too often will be considered spam

### `violation_limit`

How many times in a row a player must spam to receive a chat restriction

### `violation_reset_time`

How long each violation will be valid in ticks (20 ticks = 1 second)

### `interval`

The minimum time between messages in ticks (20 ticks = 1 second). If the player sends a message faster, it will be a violation
