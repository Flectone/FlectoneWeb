### `random`

Если включено, то изображение будет выбираться случайным образом, иначе по порядку

### `values`

`server-icon-1.png` ![server icon 1](/pulse/message_status_icon_1.webp)


`server-icon-2.png` ![server icon 2](/pulse/message_status_icon_2.webp)

Список названий изображений, которые должны отображаться

Каждое название должно совпадать с именем файла в `FlectonePulse/images/`, включая расширение. Например, `server-icon-1.png` в `values` соответствует файлу `FlectonePulse/images/server-icon-1.png`.

Перед загрузкой обрежь своё изображение до квадрата, измени размер на 64x64 пикселя и экспортируй его в PNG. Переименование файла JPEG в `.png` не меняет его формат. Подойдёт любой графический редактор с экспортом в PNG, а [редактор иконок ServerBuddy](https://serverbuddy.net/tools/minecraft-server-icon-maker) позволяет обрезать изображение и скачать PNG размером 64x64 прямо в браузере. Переименуй скачанный файл так, чтобы его имя совпадало с указанным в `values`, и загрузи его в `FlectonePulse/images/`.

<Callout type="error" title="Внимание">
Изображение должно:
1. Находиться внутри папки `/FlectonePulse/images/`
2. Иметь размер **ТОЛЬКО** `64x64`   
</Callout>
