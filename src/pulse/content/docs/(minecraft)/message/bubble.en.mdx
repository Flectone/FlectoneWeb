### `disallowed_input`

A [regular expression](https://javarush.com/groups/posts/regulyarnye-vyrazheniya-v-java) to prevent showing messages. For example, `disallowed_input: "^!.*"` will block messages that start with the `!` character

### `max_length`

Maximum length of a single overhead message. If the text is longer, it will be split into several

### `read_speed`

Reading speed in words per minute

### `handicap_chars`

Additional time for short messages

### `hint_buffer_length`

Buffer length that determines how many characters to check before and after the end of a line to correctly wrap to the next line without cutting off short words. This value allows dynamic line breaking, much like in Word

### `word_break_hint`

<Callout type="warn" title="Warning">
  Overhead messages only work with `type: "HEAD_TEXT"`. If `life_time: 0`, the message duration is calculated using the formula above, and the number of overhead messages at the same time is set via `max_count`
</Callout>

A hint symbol placed when a word is broken into two lines
