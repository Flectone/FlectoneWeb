### `load_profile_property`

Будет ли `FlectonePulse` брать у `SkinsRestorer` свойство скина и использовать его для голов игроков, то есть для `<player_head>` в формате сообщений и для головы в модуле `playerlistname`

Если выключено, головы будут показывать скин, который отдаёт сам сервер

### `load_mojang_skin`

Если включено, то для offline игроков будут загружаться официальные скины, если это возможно. Это может вызывать задержку отображения сообщений
