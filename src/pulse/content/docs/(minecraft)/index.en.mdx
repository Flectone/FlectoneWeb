# What is FlectonePulse and what is it for?
FlectonePulse is a Minecraft server plugin that allows full customization of messages, chat, commands, and integrations. It provides a flexible text formatting system, automatic player language detection, and integrations with Discord, Telegram, and Twitch

| Platform                                     | Versions                      |
|----------------------------------------------|-------------------------------|
| Bukkit / Spigot / Paper / Purpur / Folia     | 1.8.8 up to the latest        |
| Fabric                                       | Latest Minecraft version      |
| NeoForge                                     | Latest Minecraft version      |
| BungeeCord / Waterfall                       | Latest version                |
| Velocity                                     | Latest version                |

<Callout type="warn" title="Warning">
    Java 17 or higher is required. Older Minecraft versions, such as 1.8.8, can also run on Java 17 (check [PandaSpigot](https://github.com/hpfxd/pandaspigot))
</Callout>

<Callout type="info" title="Information">
    There is also a version for [Hytale](/pulse/docs/hytale/), it has its own documentation because some modules work differently there
</Callout>

<br></br>

|---------------------|--------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `config.yml`        | [Configuration](/pulse/docs/config/)                                                  | The main configuration of FlectonePulse, essential for correct operation. Database, plugin language, proxy mode, etc., are configured here.                            |
| `command.yml`       | [Commands](/pulse/docs/command/)                                                      | Configuration of all **custom** commands. They can be used by typing `/flectonepulse:name` in Minecraft.                                                                  |

| `localizations/...` | Specified in each section of command and message documentation                        | This folder contains files with settings for each player language ([see language](/pulse/docs/config/language/)). The message **format** (i.e., text) is configured here.             |
| `permission.yml`    | Specified in each section of command, message, and integration documentation            | Access rights configuration. By default, permissions are set so that most functions are available to all players without additional configuration.                   |

# Can certain plugin features be disabled?
Yes, FlectonePulse uses a modular system. Any feature (commands, messages, or integrations) can be disabled in `command.yml`, `message.yml`, or `integration.yml` respectively. After making changes, reload the plugin with `/flectonepulse reload`.

<Callout type="info" title="Information">
    Every module depends on the parent above it. If `message.enable` is disabled, all messages inside are disabled too, even if they have `enable: true`. More details in the [configuration](/pulse/docs/config/internal/)
</Callout>

<br></br>

# How does automatic language detection work?
If the `by_player` option is enabled in `config.yml`, the plugin automatically detects the player's Minecraft language and displays messages from the `localizations/...` folder in that language. If the localization is unavailable, the default language from the configuration is used. Details in the [localization documentation](/pulse/docs/config/language/).

<br></br>

# What integrations does FlectonePulse support?
The plugin integrates with Discord, Telegram, and Twitch, allowing players to communicate across platforms. Third-party Minecraft plugins are supported too, for example `LuckPerms` and `Vault` for permissions and groups, `PlaceholderAPI` and `MiniPlaceholders` for placeholders, `SkinsRestorer` for skins, `PlasmoVoice` and `SimpleVoice` to stop muted players from talking, `LiteBans`, `LibertyBans`, `AdvancedBan` and `CMI` for moderation. Integrations are configured in `integration.yml`. Details in the [integrations documentation](/pulse/docs/integration/).

<br></br>

# Why do commands or messages not work for regular players?
Most likely it is about permissions. All permissions are in `permission.yml`, each one has a `name` (the permission itself) and a `type` (who has it by default).

<Callout type="warn" title="Warning">
    If `LuckPerms` has the `* false` rule (all permissions are disabled and given manually), permissions with `type: "TRUE"` stop working too. There is the [`always_have_true`](/pulse/docs/integration/luckperms/) setting in `integration.yml` for this
</Callout>

To give a permission to a specific group, take the `name` of the permission from `permission.yml` and grant it, for example `/lp group default permission set flectonepulse.module.command.me true`

<br></br>

# A message does not appear, what should I check?
<Steps>
    <Step>
        Whether the module itself and its parent are enabled in `message.yml` or `command.yml` (`enable: true`)
    </Step>
    <Step>
        Whether the player has the module's permission from `permission.yml`
    </Step>
    <Step>
        Whether the `range` fits, for example with `range: 100` only nearby players see the message
    </Step>
    <Step>
        Whether the line in the localization file is not empty, because an empty message is not sent
    </Step>
    <Step>
        Reload the plugin with `/flectonepulse reload` and look at the console
    </Step>
</Steps>

<br></br>

# How to send messages from Minecraft to Discord or Telegram?
Put the bot token into `integration.yml`, enable the integration and add the message type to `message_channel`, where the value is the channel ID

```yaml
message_channel:
  MESSAGE_CHAT_GLOBAL:
    - "123456"
  COMMAND_BAN:
    - "123456"
```

Message type names match module names, for example `COMMAND_BAN` or `MESSAGE_CHAT_GLOBAL`. For your own chat named `admin` it will be `MESSAGE_CHAT_ADMIN`

<Callout type="info" title="Information">
    The Telegram channel ID can be found with the `!id` command right in the chat if the bot is added there. Details in the [Discord](/pulse/docs/integration/discord/), [Telegram](/pulse/docs/integration/telegram/) and [Twitch](/pulse/docs/integration/twitch/) documentation
</Callout>

# Why are heads, sprites and textures not displayed in chat?
The [object](/pulse/docs/message/format/object/) module only works for players on version `1.21.9` and above. Everyone else sees the plain symbol from `default_symbol` instead of a head or an icon

<br></br>

# Why are chat messages duplicated?
Most often it is another plugin that also sends the message. Check `cancel` of the chat in `message.yml` – with `cancel: false` FlectonePulse does not cancel the event, so the message can be sent by the server and by another plugin.

Duplication also happens with plugins that modify chat packets (for example `InteractiveChat`) or with `DiscordSRV` if it has its own Webhook messages enabled. Details in the [chat](/pulse/docs/message/chat/#mode)

<br></br>

# How to move all settings to another server?
There are ready commands for this
<Steps>
    <Step>
        On the first server write `/flectonepulse export`, this creates a `.zip` archive in the `FlectonePulse` folder
    </Step>
    <Step>
        Move this archive to the `FlectonePulse` folder on the other server
    </Step>
    <Step>
        Write `/flectonepulse import archive_name`, after which the plugin reloads with the new settings
    </Step>
</Steps>

Details in the [command documentation](/pulse/docs/command/flectonepulse/)

Yes, there is a web editor for that. Put `host` and `port` into `command.yml`, then write `/flectonepulse editor` and open the returned link

# What happens to the configs when the plugin updates?
FlectonePulse adds new settings and carries over old values itself, so there is no need to delete the configs. Before that, a copy of the old files and of the database is created in the `FlectonePulse/backups/old_version` folder

<Callout type="warn" title="Warning">
    Do not change `version` in `config.yml` manually, the plugin uses it to know which version to migrate the settings from
</Callout>

# Does FlectonePulse support PlaceholderAPI?
Yes, FlectonePulse is fully compatible with PlaceholderAPI and MiniPlaceholders. Use placeholders in messages.

FlectonePulse adds its own placeholders too, for example `%flectonepulse_ping%` or `%flectonepulse_online_total_formatted%`. The full list is in the [PlaceholderAPI](/pulse/docs/integration/placeholderapi/) and [MiniPlaceholders](/pulse/docs/integration/miniplaceholders/) documentation

# How is FlectonePulse different from FlectoneChat?
FlectonePulse is a new project, not an improved version of FlectoneChat. FlectoneChat was an experiment, while FlectonePulse was created with past mistakes in mind, offering more features and customization.

# How to configure the TAB (player list)?
To enable/disable TAB modules, configure `message.yml`:

```yaml
tab:
  enable: true
  header:
    enable: true
  footer:
    enable: true
  playerlistname:
    enable: true
```

To change the messages, edit the `localizations/...` file:

```yaml
tab:
  header:
    lists:
    - - " "
      - "<fcolor:1>👾"
      - " "
    - - " "
      - "<fcolor:1>❤"
      - " "
  footer:
    lists:
    - - " "
      - "<fcolor:1>Hello <fcolor:2><nickname><fcolor:1>!"
      - " "
    - - " "
      - "<fcolor:1>TPS <replacement:tps>, Online <replacement:online>"
      - " "
  playerlistname:
    format: "<!shadow><white><player_head></white></!shadow><world>▋ <reset><prefix><stream><fcolor:2><nickname><afk><mute><suffix>"
```

<Callout type="warn" title="Warning">
To sort the TAB by donation groups, enable [`tab_sort`](/pulse/docs/integration/luckperms/#tab-sort).
</Callout>

After the changes, run `/flectonepulse reload`. Details in the [TAB documentation](/pulse/docs/message/tab/).

# What to do if errors occur?
<Steps>
    <Step>
        Check the server console for errors
    </Step>
    <Step>
        Make sure you are using the latest version of the plugin
    </Step>
    <Step>
        Write `/flectonepulse dump`, this command collects information about the server and the plugin and returns a link, which is convenient to send to support
    </Step>
    <Step>
        Send the error and the link to the [Discord community](https://discord.com/channels/861147957365964810/1271850075064369152) or get personal technical support for boosters on [Boosty](https://boosty.to/thefaser)
    </Step>
</Steps>

<Callout type="info" title="Information">
    If the server does not start and the log is cut off, run it with the `-Dflectonepulse.debug=true` flag, then there will be more information in the console
</Callout>

# When will a new version of FlectonePulse with support for the latest Minecraft version be released?
Most likely FlectonePulse already supports the newest Minecraft version. Experimental builds are available on [GitHub](https://github.com/Flectone/FlectonePulse/actions/) or in the [Discord channel for testers](https://discord.com/channels/861147957365964810/1357058707011272926). If a Minecraft version is already out but the FlectonePulse update is missing, it is because of waiting for the PacketEvents release – the main library FlectonePulse uses to work with the server. As soon as PacketEvents is released, FlectonePulse will be updated.

<Callout type="warn" title="Warning">
Use test builds at your own risk. These builds are usually not made for production, they can be broken or break your previous FlectonePulse version
</Callout>

# Does FlectonePulse work with a proxy and how to set it up?
FlectonePulse supports proxy servers, including BungeeCord and Velocity. The same plugin file must be installed both on the proxy and on the servers. Configuration files are not created on the proxy – it acts as a bridge. All settings are made in the files on the servers. A server database (`MySQL`, `MariaDB` or `PostgreSQL`) is required and must be configured in `config.yml` on the servers. You also need to enable either the `velocity` or the `bungeecord` mode, details in the [configuration documentation](/pulse/docs/config/proxy/).

<Callout type="info" title="Information">
    Instead of `BungeeCord` and `Velocity`, `Redis` can be used to link the servers, then the servers do not even need a shared proxy
</Callout>

<br></br>

# Does FlectonePulse support cores that run both mods and plugins, such as Arclight or Mohist?

FlectonePulse has not been tested on cores that support both mods and plugins (such as Arclight or Mohist), and it is not intended to support them, but it may work. The main issue is the PacketEvents library, as with Fabirc/NeoForge, where some mods may create their own protocols or modify existing ones, causing players to crash

The separate `Fabric` and `NeoForge` builds only work on the very latest Minecraft version because of how hard multi-version support is

<br></br>

# My plugin that uses chat is incompatible with FlectonePulse?

By default `FlectonePulse` uses `mode: "BUKKIT"` for [chats](/pulse/docs/message/chat/#mode), with it other plugins also see chat messages

<Callout type="info" title="Information">
    In rare cases, if your plugin uses `Paper` listeners, you need to set `mode: "PAPER"`. And `mode: "PACKET"` on the contrary takes the chat over completely through `PacketEvents`, with it other plugins do not see the messages
</Callout>

If the plugin still conflicts, try changing the chat `priority`, for example to `HIGHEST`, so that FlectonePulse modifies the message last
