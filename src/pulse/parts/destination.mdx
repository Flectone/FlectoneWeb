### `destination`

Куда будет отправлено сообщение

| Тип           | Объяснение                                    | Требует дополнительной настройки? |
|---------------|----------------------------------------------|-----------------------------------|
| `ACTION_BAR`  | Сообщение над инвентарём игрока              | Да                                |
| `BOSS_BAR`    | Сообщение в верхней части экрана             | Да                                |
| `BRAND`       | Сообщение в F3                               | Нет                               |
| `CHAT`        | Сообщение в чат                              | Нет                               |
| `HEAD_TEXT`   | Сообщение над головой игрока                 | Да                                |
| `TITLE`       | Сообщение на весь экран                      | Да                                |
| `SUBTITLE`    | Сообщение на весь экран (нижняя строчка)     | Да                                |
| `TAB_HEADER`  | Сообщение в ТАБ (сверху)                     | Нет                               |
| `TAB_FOOTER`  | Сообщение в ТАБ (снизу)                      | Нет                               |
| `TOAST`       | Сообщение в правом верхнем углу (достижение) | Да                                |

                <Accordion title={<code>BOSS_BAR</code>}>

                    ![action bar](/pulse/destination_boss_bar.webp)

                    ```yaml
                    destination:
                      type: "BOSS_BAR"
                      duration: 100
                      health: 1.0
                      overlay: "PROGRESS"
                      color: "BLUE"
                      play_boos_music: false
                      create_world_fog: false
                      darken_screen: false
                    ```

                    `duration`

                    Длительность отображения сообщения

                    `health`

                    Насколько будет заполнена шкала bossbar

                    `overlay`

                    | Тип          | Объяснение                |
                    |--------------|--------------------------|
                    | `PROGRESS`   | Одной линией             |
                    | `NOTCHED_6`  | Разделённое на 6 частей  |
                    | `NOTCHED_10` | Разделённое на 10 частей |
                    | `NOTCHED_12` | Разделённое на 12 частей |
                    | `NOTCHED_20` | Разделённое на 20 частей |

                    `color`

                    Цвет отображения (`PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE`)

                    `play_boos_music`

                    Будет ли музыка при сообщении

                    `create_world_fog`

                    Будет ли туман при сообщении

                    `darken_screen`

                    Будет ли затемнён экран при сообщении


                </Accordion>
            </Accordions>

            <Accordions>
                <Accordion title={<code>HEAD_TEXT</code>}>
                    ![head text](/pulse/destination_head_text.webp)

                    <Callout type='info' title="Информация">
                        Текст появляется над головой отправителя, поэтому работает только для сообщений от игрока
                    </Callout>

                    ```yaml
                    destination:
                      type: "HEAD_TEXT"
                      visible_to_self: true
                      hide_when_sneaking: false
                      filter_ignores: false
                      movable: true
                      row: 0
                      max_count: 1
                      distance: 30.0
                      life_time: 0
                      modern:
                        enable: true
                        has_shadow: true
                        see_through: false
                        disable_see_through_when_sneaking: true
                        background: "#00000040"
                        animation_time: 5
                        offset_x: 0.0
                        offset_y: 0.2
                        offset_z: 0.0
                        scale: 1.0
                        scale_with_player: false
                        space: 0.3
                        billboard: "CENTER"
                    ```

                    `visible_to_self`

                    Будет ли игрок видеть собственный текст над головой

                    `hide_when_sneaking`

                    Будет ли текст скрываться, когда игрок присел

                    `filter_ignores`

                    Если включено, то игроки, которые игнорируют владельца текста, не будут его видеть

                    `movable`

                    Можно ли сдвигать текст. Если `true`, то каждый новый текст поднимает старые выше. Если `false`, то текст всегда остаётся на своей строке `row` и просто обновляется

                    `row`

                    Строка над головой, с которой начинается текст. `0` – самая нижняя строка

                    `max_count`

                    Максимальное количество текстов от одного модуля над головой одновременно

                    `distance`

                    Насколько далеко в блоках можно увидеть текст

                    `life_time`

                    Время в тиках (20 тиков = 1 секунда), сколько будет показываться текст. Если будет `0`, то время рассчитывается автоматически, а если `-1`, то текст будет показываться всегда

                    `modern`

                    Текст над головой через Text Display

                    <Callout type='warn' title="Предупреждение">
                        `modern` будет использован только для игроков с версией `1.19.4` и выше, для остальных будет устаревший `area effect cloud`
                    </Callout>

                    | Поле | Объяснение |
                    |------|------------|
                    | `enable` | Включает работоспособность |
                    | `has_shadow` | Включает тень у текста |
                    | `see_through` | Будет ли текст виден сквозь блоки |
                    | `disable_see_through_when_sneaking` | Отключает `see_through`, когда игрок присел |
                    | `background` | Цвет фона текста, он имеет прозрачность т.е. альфа-канал. [Сайт для выбора цвета](https://rgbacolorpicker.com/color-wheel-picker) |
                    | `animation_time` | Время в тиках, сколько будет идти анимация появления и исчезновения. Если будет 0 или меньше, то анимации не будет |
                    | `offset_x` | Смещение по координате X относительно головы игрока |
                    | `offset_y` | Смещение по координате Y (вверх +, вниз -) относительно головы игрока |
                    | `offset_z` | Смещение по координате Z относительно головы игрока |
                    | `scale` | Насколько большим будет текст |
                    | `scale_with_player` | Будут ли `scale`, смещения и `space` умножаться на размер игрока. Например, если игрок стал меньше через атрибут `scale` |
                    | `space` | Расстояние между строками |
                    | `billboard` | Как текст поворачивается к игроку: `FIXED` не поворачивается, `VERTICAL` по вертикали, `HORIZONTAL` по горизонтали, `CENTER` по вертикали и горизонтали |
                </Accordion>
            </Accordions>

            <Accordions>
                <Accordion title={<code>TITLE (или SUBTITLE)</code>}>
                    ![title](/pulse/destination_title.webp)

                    ```yaml
                    destination:
                      type: "TITLE" (или "SUBTITLE")
                      subtext: ""
                      times:
                        fade_in: 20
                        stay: 60
                        fade_out: 20
                    ```

                    `subtext`

                    Сообщение для второй части отображения. Например, если выбран `TITLE`, то `subtext` будет показываться под ним и наоборот

                    `times`

                    | Поле       | Объяснение                            |
                    |------------|--------------------------------------|
                    | `fade_in`  | Время в тиках на появление сообщения |
                    | `stay`     | Время в тиках на удержание сообщения |
                    | `fade_out` | Время в тиках на удаления сообщения  |

                </Accordion>
            </Accordions>

            <Accordions>
                <Accordion title={<code>TOAST</code>}>
                    ![toast](/pulse/destination_toast.webp)
                    ```yaml
                    destination:
                      type: "TOAST"
                      icon: "minecraft:diamond"
                      subtext: ""
                      style: "TASK"
                    ```

                    `icon`

                    Иконка достижения, которая может быть любым предметом из майнкрафта (нужно обязательно указывать полный путь)

                    `subtext`

                    Описание достижения, не используется

                    `style`

                    Вид достижения (`TASK` обычное, `GOAL` цель, `CHALLENGE` челлендж)
                </Accordion>
            </Accordions>
