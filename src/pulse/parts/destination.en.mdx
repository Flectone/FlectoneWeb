### `destination`

Where the message will be sent

| Type          | Explanation                                  | Requires additional configuration? |
|---------------|----------------------------------------------|-----------------------------------|
| `ACTION_BAR`  | Message above the player's inventory         | Yes                               |
| `BOSS_BAR`    | Message at the top of the screen             | Yes                               |
| `BRAND`       | Message in F3                                | No                                |
| `CHAT`        | Message in chat                              | No                                |
| `HEAD_TEXT`   | Message above the player's head              | Yes                               |
| `TITLE`       | Full-screen message                          | Yes                               |
| `SUBTITLE`    | Full-screen message (bottom line)            | Yes                               |
| `TAB_HEADER`  | Message in TAB (top)                         | No                                |
| `TAB_FOOTER`  | Message in TAB (bottom)                      | No                                |
| `TOAST`       | Message in the top right corner (achievement)| Yes                               |

            <Accordions>
                <Accordion title={<code>BOSS_BAR</code>}>

                    ![action bar](/pulse/destination_boss_bar.webp)

                    ```yaml
                    destination:
                      type: "BOSS_BAR"
                      duration: 100
                      health: 1.0
                      overlay: "PROGRESS"
                      color: "BLUE"
                      play_boos_music: false
                      create_world_fog: false
                      darken_screen: false
                    ```

                    `duration`

                    Duration of the message display

                    `health`

                    How much the bossbar scale will be filled

                    `overlay`

                    | Type         | Explanation              |
                    |--------------|--------------------------|
                    | `PROGRESS`   | Single line              |
                    | `NOTCHED_6`  | Divided into 6 parts     |
                    | `NOTCHED_10` | Divided into 10 parts    |
                    | `NOTCHED_12` | Divided into 12 parts    |
                    | `NOTCHED_20` | Divided into 20 parts    |

                    `color`

                    Display color (`PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE`)

                    `play_boos_music`

                    Whether there will be music with the message

                    `create_world_fog`

                    Whether there will be fog with the message

                    `darken_screen`

                    Whether the screen will be darkened with the message

                </Accordion>
            </Accordions>

            <Accordions>
                <Accordion title={<code>HEAD_TEXT</code>}>
                    ![head text](/pulse/destination_head_text.webp)

                    <Callout type='info' title="Information">
                        The text appears above the sender's head, so it only works for messages sent by a player
                    </Callout>

                    ```yaml
                    destination:
                      type: "HEAD_TEXT"
                      visible_to_self: true
                      hide_when_sneaking: false
                      filter_ignores: false
                      movable: true
                      row: 0
                      max_count: 1
                      distance: 30.0
                      life_time: 0
                      modern:
                        enable: true
                        has_shadow: true
                        see_through: false
                        disable_see_through_when_sneaking: true
                        background: "#00000040"
                        animation_time: 5
                        offset_x: 0.0
                        offset_y: 0.2
                        offset_z: 0.0
                        scale: 1.0
                        scale_with_player: false
                        space: 0.3
                        billboard: "CENTER"
                    ```

                    `visible_to_self`

                    Whether the player will see their own text above their head

                    `hide_when_sneaking`

                    Whether the text will be hidden while the player is sneaking

                    `filter_ignores`

                    If enabled, players who ignore the text owner will not see it

                    `movable`

                    Whether the text can be moved. If `true`, each new text pushes the old ones higher. If `false`, the text always stays on its `row` and is simply updated

                    `row`

                    The row above the head where the text starts. `0` is the lowest row

                    `max_count`

                    Maximum number of texts from one module above the head at the same time

                    `distance`

                    How far away in blocks the text can be seen

                    `life_time`

                    Time in ticks (20 ticks = 1 second) for the text to be displayed. If `0`, the time is calculated automatically, and if `-1`, the text will always be shown

                    `modern`

                    Text above the head via Text Display

                    <Callout type='warn' title="Warning">
                        `modern` will only be used for players on version `1.19.4` and higher, the others will get the legacy `area effect cloud`
                    </Callout>

                    | Field | Explanation |
                    |------|------------|
                    | `enable` | Enables functionality |
                    | `has_shadow` | Enables text shadow |
                    | `see_through` | Whether the text is visible through blocks |
                    | `disable_see_through_when_sneaking` | Disables `see_through` while the player is sneaking |
                    | `background` | Text background color, it has transparency (alpha channel). [Site for color selection](https://rgbacolorpicker.com/color-wheel-picker) |
                    | `animation_time` | Time in ticks for the appearance and disappearance animation. If 0 or less, there will be no animation |
                    | `offset_x` | Offset along the X coordinate relative to the player's head |
                    | `offset_y` | Offset along the Y coordinate (up +, down -) relative to the player's head |
                    | `offset_z` | Offset along the Z coordinate relative to the player's head |
                    | `scale` | How big the text will be |
                    | `scale_with_player` | Whether `scale`, offsets and `space` are multiplied by the player's size. For example, if the player became smaller via the `scale` attribute |
                    | `space` | Distance between rows |
                    | `billboard` | How the text turns toward the player: `FIXED` does not turn, `VERTICAL` vertically, `HORIZONTAL` horizontally, `CENTER` vertically and horizontally |
                </Accordion>
            </Accordions>

            <Accordions>
                <Accordion title={<code>TITLE (or SUBTITLE)</code>}>
                    ![title](/pulse/destination_title.webp)

                    ```yaml
                    destination:
                      type: "TITLE" (or "SUBTITLE")
                      subtext: ""
                      times:
                        fade_in: 20
                        stay: 60
                        fade_out: 20
                    ```

                    `subtext`

                    Message for the second part of the display. For example, if `TITLE` is selected, `subtext` will be shown below it and vice versa

                    `times`

                    | Field      | Explanation                          |
                    |------------|--------------------------------------|
                    | `fade_in`  | Time in ticks for message appearance |
                    | `stay`     | Time in ticks to hold the message    |
                    | `fade_out` | Time in ticks for message removal    |

                </Accordion>
            </Accordions>

            <Accordions>
                <Accordion title={<code>TOAST</code>}>
                    ![toast](/pulse/destination_toast.webp)
                    ```yaml
                    destination:
                      type: "TOAST"
                      icon: "minecraft:diamond"
                      subtext: ""
                      style: "TASK"
                    ```

                    `icon`

                    Achievement icon, which can be any item from Minecraft (must specify the full path)

                    `subtext`

                    Achievement description, not used

                    `style`

                    Achievement type (`TASK` regular, `GOAL` goal, `CHALLENGE` challenge)
                </Accordion>
