### `range`

How far in blocks the message will be displayed

| Value                                                                             | Explanation                                                                                                                                                                                                                                                                                                                                         |
|-----------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `PERMISSION` (or any value that contains `.`, for example `range: "custom.admin"` | The message will be sent only to players who have the specified permission `custom.admin`, if the permission is not specified, then the permission `flectonepulse.permission.` + module name will be checked. For example, if `range: "PERMISSION"` is specified in the `chat` module, then `flectonepulse.permission.message_chat` will be checked |
| `WORLD_TYPE`                                                                      | The message will be sent only to players who have the permission `flectonepulse.world.type.dimension_name`                                                                                                                                                                                                                                          |
| `WORLD_NAME`                                                                      | The message will be sent only to players who have the permission `flectonepulse.world.name.world_folder_name`                                                                                                                                                                                                                                       |
| `PROXY`                                                                           | The message will be sent to all players on the server and on [Proxy](/pulse/docs/config/proxy/#bungeecord)                                                                                                                                                                                                                                          |
| `SERVER`                                                                          | The message will be sent to all players on the server                                                                                                                                                                                                                                                                                               |
| `PLAYER`                                                                          | The message will be sent only to the sender                                                                                                                                                                                                                                                                                                         |
| any number that is greater than `0`, for example `range: 100`                     | The message will be sent to players whose distance between them and the sender is **less** than this number. Also players must be in the same world as the sender                                                                                                                                                                                   |
